Biological Reasoning Models

Measuring Evidence Use in Biological Reasoning Models

When a model predicts a disease from a genetic variant, how much of its answer comes from the DNA?

Motivation

A pathway description can hint at a disease before a model even sees the genetic variant. That makes a correct prediction hard to interpret. We study how to tell whether a biological reasoning model uses the measurements it receives, and whether changing its training or the tools it can use makes it more responsive to that evidence.

Prior work

Fang and colleagues tested biological reasoning models by keeping a question fixed while changing the sequence or cell measurements that accompanied it. They found that some models gave similar answers after the biological input was scrambled. We adopted their comparison for a disease-prediction task where the same pathway description can accompany variants associated with different diseases.

What we found

We released code that compares the same model with intact DNA, scrambled DNA, and text alone. On this benchmark BioReason gained 17 percentage points when given intact DNA alongside the text, but scrambling the sequence left its accuracy similar. I’m extending this question to drug-target prioritization, where the goal is to test whether changing the evidence changes which candidate a model ranks first.
